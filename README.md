## GitHub Pages

1. Create a new public repository, for example `nandini-portfolio`.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Your URL will normally be:

`https://YOUR-GITHUB-USERNAME.github.io/nandini-portfolio/`

If you later create a repository named exactly `YOUR-GITHUB-USERNAME.github.io`, the site can use the shorter root URL.
